How these numbers are counted

Visits come from successful website page loads in retained server logs. API polling, live streams, assets and recognised bots are excluded. Navigating between sections without reloading does not add a page load.

Visitors are estimates, not distinct people: shared networks and browser changes affect the count. Only daily salted identifiers are stored in the statistics database, never raw IP addresses, browser headers, passwords or API keys.

Registrations count existing accounts by creation date. Tables and creators count account-owned tables by creation date, including subsequently deleted tables. Legacy unclaimed tables are excluded. Daily visitor and creator counts must not be summed as unique users across a date range.

Collection runs independently every minute. Game data is queried read-only with a short timeout. If a source is temporarily unavailable, the dashboard keeps its last successful data and displays a warning.
